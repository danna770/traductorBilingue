☁ Sincronización automática (GitHub)

Sincronizá automáticamente tus palabras y secciones entre tu PC, GitHub Pages y tu celular usando un Gist privado en tu cuenta de GitHub.

Cómo activarlo en 1 minuto:
1. En GitHub andá a Settings → Developer settings → Personal access tokens → Tokens (classic).
2. Creá un token marcando solo el permiso gist.
3. Pegalo acá abajo y tocá Conectar y sincronizar. En otro dispositivo pegás el mismo token y la app encuentra tu nube sola.
